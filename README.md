# skills

Agent skills for AI harnesses like Claude Code/Codex/Gemini from [langmail](https://langmail.me).

## Installation

```bash
npx skills add langmail/skills --skill SKILLNAME
```

## Available Skills

### langmail

Rules for working with emails, calendar appointments, and contacts in a langmail environment: marks emails as read or starred by importance, archives finished todos, adds invitations to the calendar, and flags attendees who haven't answered.

```bash
npx skills add langmail/skills --skill langmail
```

Or in Claude Code:

```
/plugin install langmail --marketplace langmail/skills
```
