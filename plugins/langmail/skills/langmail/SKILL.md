# Email Rules

- Whenever you read a not important email from langmail, mark it as `read`.
- Whenever you read an important email from langmail, mark it as `starred`. Do not mark it as `read`.
- Whenever you read an email from langmail, that was flagged with a `todo` keyword and this todo is done, remove the keyword and archive the email.
- Whenever you get an appointment invitation, check if it's already in the calendar. If not, add it to the calendar, if you're sure the user is attending. If not, ask the user.

# Calendar Rules

- When checking the calendars for today's schedule, check if everybody who is supposed to attend has answered. If not, tell the user.
